# WristAct field test

Phone page for testing a wrist activity classifier (XIAO nRF52840 Sense) on the move.
It connects to the board over Bluetooth (Nordic UART Service) with Web Bluetooth,
starts a session, and shows the board's class for each 10 s window next to what you
say you're doing.

Open https://austingoodnight.github.io/wristact-field/ in Chrome on Android, or in the
Bluefy browser on iPhone (Safari has no Web Bluetooth).
